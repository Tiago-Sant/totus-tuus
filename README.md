# Consagração a Jesus por Maria – Organizador de Preparação

Este aplicativo foi criado para ajudar fiéis a se prepararem e renovarem a Consagração a Jesus por Maria, segundo o método de São Luís Maria Grignion de Montfort, conforme descrito no livro "Tratado da Verdadeira Devoção à Santíssima Virgem Maria".

## Descrição

O app facilita a organização da preparação para a consagração, guiando o usuário na escolha das datas, etapas e orações, respeitando as duas formas tradicionais de preparação: 30 ou 33 dias. Ele elimina dúvidas comuns sobre o cronograma, tornando o processo mais simples e acessível.

## Motivação

Muitos consagrados e pessoas que desejam se consagrar têm dúvidas sobre:
- Qual data escolher para a consagração
- Como contar corretamente os 30 ou 33 dias de preparação
- Quais orações e etapas seguir em cada período

Este app nasceu para ajudar a esclarecer essas questões e tornar a vivência da consagração mais tranquila e organizada.

## Como funciona

- **Escolha a data da consagração:** O app sugere datas marianas e permite escolher qualquer outra data.
- **Escolha o método:** Você pode optar por 30 ou 33 dias de preparação, conforme as tradições.
- **Cronograma automático:** O app calcula e exibe o cronograma completo, indicando o início, as etapas e as orações de cada dia.
- **Acesso às orações:** Todas as orações necessárias para cada etapa estão disponíveis no próprio app.

## Espiritualidade

O método seguido é o de São Luís Maria Grignion de Montfort, que propõe uma preparação profunda para a entrega total a Jesus pelas mãos de Maria. Este aplicativo é apenas um auxílio prático para a organização do caminho espiritual, mas não substitui a vivência da fé, a oração pessoal e a participação nos sacramentos.

## Tecnologias utilizadas

- shadcn/ui
- Tailwind CSS

## Execução local (opcional)

1. Instale as dependências:
   ```bash
   npm install
   ```
2. Rode o projeto:
   ```bash
   npm run dev
   ```
